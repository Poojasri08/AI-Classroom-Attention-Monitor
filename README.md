# AI Classroom Attention Monitoring System

An AI-powered real-time classroom attention monitoring system built using Python, OpenCV, and MediaPipe.

## Features

* Real-time webcam monitoring
* Drowsiness detection
* Eye tracking using facial landmarks
* Head movement detection
* Attention percentage analytics
* Lightweight and optimized processing

## Technologies Used

* Python
* OpenCV
* MediaPipe

## How It Works

The system uses computer vision and facial landmark tracking to monitor:

* Eye openness for drowsiness detection
* Head direction for focus estimation
* Attention percentage based on user focus and alertness

## Installation

Clone the repository:

```bash
git clone https://github.com/Poojasri08/AI-Classroom-Attention-Monitoring-System.git
```

Install dependencies:

```bash
pip install opencv-python mediapipe
```

Run the project:

```bash
python main.py
```

Press `q` to exit the webcam window.
